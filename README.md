# Boys at the Back

Private group chat for the boys.

## How to use

1. Open the live site: **https://lizer-webcoder.github.io/Boys-at-the-Back/**  
   (or open `index.html` locally)

2. Enter your name
3. Leave Room ID empty to create a new room, or type an existing one to join
4. Share the Room ID with the boys

## Features
- Real-time text chat
- No accounts needed
- Works on phone and desktop (browser)
- Completely free

## Deploy / Update
This repo is already set up for GitHub Pages.
Just make sure GitHub Pages is enabled (Settings → Pages → Source: Deploy from branch `main`).
